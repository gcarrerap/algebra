# Video scripts

The written script of every video, **the step before `script.json`, audio and animation**.
Each script has the video's objective, the topics it covers, the full transcript (exactly what
the narrator says), the reflection pauses, and notes on what the screen shows. Format, pause
rules and how a script becomes a video: [docs/video-scripts.md](../docs/video-scripts.md).

| File | Contents |
|---|---|
| [`u00.md`](u00.md) … [`u13.md`](u13.md) | Lesson videos of each unit, in syllabus order. |
| [`u00-l01-solutions.md`](u00-l01-solutions.md), [`u00-l02-solutions.md`](u00-l02-solutions.md) | The 40 produced solution videos of practice sets 0.1 and 0.2 (generated). |

## How the topics were split

Every topic got a script first; its estimated length (narration at the narrator's measured pace
plus every pause) decided whether it is one video or several:

- **0.1** is split into *0.1.1 Order of operations* (produced) and *0.1.2 Signed numbers*: the
  practice set needs signed-number arithmetic the produced video doesn't teach, and both in one
  video would run 7:49.
- **0.2** keeps its two produced subtopics (together 7:48).
- **1.1, 1.2, 1.4 and 12.4** were drafted as two subtopics each, but each pair estimated under
  7 minutes, so each is one video.
- No other topic comes near the 7-minute target limit, so the rest stay single videos.

Totals: 72 lesson videos, about 4 hours with pauses; every one has at least two 10–15 s
reflection pauses and one 15–30 s "pause and try it".
