## 2.1 · Relations and functions
- **Video:** `u02-l01-relations-and-functions`
- **Status:** script
- **Estimated length:** 3:55 (speech 2:43 · pauses 54 s · 407 words · 5 scenes)

**Objective.** Ana decides whether a relation is a function from a table, a mapping diagram,
a set of points or a graph (vertical line test), and explains the rule "each input has
exactly one output".

**Topics.**
- Input and output; a relation as a set of pairs.
- Function: every input has exactly one output.
- Tables and mapping diagrams.
- Repeated outputs are fine; repeated inputs with different outputs are not.
- The vertical line test on graphs.

#### S1 · A vending machine
*Screen:* a vending machine; button A1 → chips, B2 → juice.
> Press button A one on a vending machine and you get chips. Every time. That reliability is what makes it a machine you can trust.
*Screen:* A1 → chips on one press, cookies on another; a question mark.
> Now imagine pressing A one and sometimes getting chips, sometimes cookies. Would you still trust that machine?
[REFLECT 10s] *Screen:* the confused machine; countdown ring.
> A function is like a reliable machine. You give it an input, and it gives back exactly one output.

#### S2 · Relations and functions
*Screen:* `{(1, 4), (2, 5), (3, 6)}` and the same as a table x | y.
> A relation is any set of input and output pairs. We often write them as points, or in a table with inputs on the left and outputs on the right.
*Screen:* definition card: "A function assigns to each input exactly one output."
> A relation is a function when each input has exactly one output.
*Screen:* mapping diagram: inputs 1, 2, 3 → outputs 4, 5, 6, one arrow each.
> In a mapping diagram, draw an arrow from each input to its output. If every input has exactly one arrow leaving it, it's a function.

#### S3 · Which are functions?
*Screen:* mapping A: 1 → 7, 2 → 7, 3 → 9. Mapping B: 1 → 7, 1 → 8, 2 → 9.
> Here are two mapping diagrams. In the first, one and two both go to seven. In the second, one goes to both seven and eight. Which one is a function?
[REFLECT 12s] *Screen:* both diagrams; countdown ring.
*Screen:* A gets a green check; B's two arrows from 1 turn red.
> The first one is a function. Two inputs can share an output, like two buttons that both give chips. The second is not a function: the input one has two different outputs.
*Screen:* table x: 2, 4, 2, 6 · y: 3, 5, 3, 1.
> In a table, look for repeated inputs. Here two appears twice, but both times with output three. That's the same pair written twice, so it's still a function.

#### S4 · The vertical line test
*Screen:* coordinate plane; a line `y = 2x − 1`; a vertical line sweeps left to right, touching it once everywhere.
> On a graph, inputs are on the horizontal axis. A vertical line crosses all the points that share one input.
> So if any vertical line hits the graph more than once, some input has more than one output.
*Screen:* a sideways parabola `x = y²`; the vertical line at x = 4 hits (4, 2) and (4, −2), both in red.
> This sideways curve fails. At x equals four, the vertical line hits two points, four comma two and four comma negative two. It is not a function.
*Screen:* a circle; a vertical line hits twice.
> A circle fails too.
> Here's a question to turn over: does a horizontal line hitting a graph twice tell you anything about whether it's a function?
[REFLECT 12s] *Screen:* a parabola `y = x²` with a horizontal line hitting it twice; countdown ring.
> No. That means two inputs share an output, which is allowed. Only vertical lines test for functions.

#### S5 · Your turn
*Screen:* (a) points `{(−1, 2), (0, 2), (1, 2)}` · (b) table x: 3, 3 · y: 0, 5 · (c) a graph shaped like a "C".
> Your turn. Decide which of these three relations are functions, and explain each one. Pause the video and try it.
[TRY IT 20s] *Screen:* countdown ring.
*Screen:* (a) ✓ · (b) ✗ input 3 has outputs 0 and 5 · (c) ✗ fails the vertical line test.
> The first is a function: every input gives two, and sharing an output is fine. The second is not: three goes to zero and to five. The third fails the vertical line test.
> Remember: a function gives each input exactly one output. Check inputs in tables, arrows in mapping diagrams, and vertical lines on graphs.
> This video uses an AI-generated voice.

## 2.2 · Function notation
- **Video:** `u02-l02-function-notation`
- **Status:** script
- **Estimated length:** 4:09 (speech 3:02 · pauses 47 s · 455 words · 6 scenes)

**Objective.** Ana reads and writes function notation, evaluates `f(a)` for numbers and
expressions, solves `f(x) = k`, and interprets `f(a)` in context.

**Topics.**
- `f(x)` is read "f of x", not "f times x".
- Evaluating: substitute and compute.
- Inputs that are negative or expressions: `f(−2)`, `f(a + 1)`.
- `f(a)` vs. `f(x) = k`: give the input vs. find the input.
- Meaning in context.

#### S1 · A name for the rule
*Screen:* `y = 3x + 1` → `f(x) = 3x + 1`.
> Here's a rule: multiply by three, then add one. We could write y equals three x plus one. Function notation gives the rule a name: f of x equals three x plus one.
*Screen:* `f(x)` with labels: f = name, x = input, f(x) = output.
> F is the function's name. X is the input. And f of x, all together, is the output.
> Careful: f of x does not mean f times x. The parentheses here hold the input.
> Why might it help to have names like f and g instead of always writing y?
[REFLECT 10s] *Screen:* `f(x) = 3x + 1` and `g(x) = x²` side by side; countdown ring.
> With names, we can talk about several functions at once, and say exactly which input we mean.

#### S2 · Evaluating
*Screen:* `f(4) = 3(4) + 1 = 13`; the 4 drops into the parentheses where x was.
> F of four means: put four in for x. Three times four plus one is thirteen. So f of four equals thirteen.
*Screen:* `f(−2) = 3(−2) + 1 = −5`.
> F of negative two: three times negative two is negative six, plus one is negative five. Put negative inputs in parentheses so the signs stay clear.
*Screen:* `g(x) = x² − 2x`; `g(−3)`.
> Now g of x equals x squared minus two x. What is g of negative three?
[THINK 5s] *Screen:* countdown ring.
*Screen:* `(−3)² − 2(−3) = 9 + 6 = 15`.
> Negative three squared is nine. Minus two times negative three is plus six. G of negative three is fifteen.

#### S3 · An expression as the input
*Screen:* `f(a + 1)`.
> The input can even be an expression. F of the quantity a plus one means: replace every x with a plus one.
*Screen:* `3(a + 1) + 1 = 3a + 3 + 1 = 3a + 4`.
> Three times the quantity a plus one, plus one. That's three a plus four.

#### S4 · Giving the output
*Screen:* `f(x) = 19`.
> Now the question flips. When is f of x equal to nineteen? This time you know the output and need the input.
*Screen:* `3x + 1 = 19` → `x = 6`.
> Set three x plus one equal to nineteen. Subtract one, divide by three. X equals six. So f of six is nineteen.
> Compare these two questions: find f of nineteen, and find x when f of x is nineteen. Are they the same question?
[REFLECT 12s] *Screen:* both questions in two cards; countdown ring.
> No. F of nineteen gives nineteen as the input and the answer is fifty-eight. The other gives nineteen as the output and the answer is six.

#### S5 · In context
*Screen:* "C(h) = 15h + 40: cost in dollars of a plumber for h hours". `C(3) = 85`.
> A plumber charges C of h equals fifteen h plus forty dollars for h hours. C of three equals eighty-five means: three hours of work cost eighty-five dollars. In context, always say what the input and the output mean.

#### S6 · Your turn
*Screen:* `h(t) = −5t² + 20t`: (a) `h(1)` (b) `h(4)` (c) what does `h(4)` mean if h is a ball's height in meters after t seconds?
> Your turn. H of t equals negative five t squared plus twenty t gives a ball's height in meters after t seconds. Find h of one and h of four, and say what h of four means. Pause the video and try it.
[TRY IT 20s] *Screen:* countdown ring.
*Screen:* `h(1) = 15` · `h(4) = −80 + 80 = 0` → "after 4 seconds the ball is back on the ground".
> H of one is negative five plus twenty, fifteen meters. H of four is negative eighty plus eighty, zero. After four seconds, the ball is back on the ground.
> Remember: f of x names the output for input x. To evaluate, substitute the input everywhere. To solve f of x equals k, set up an equation.
> This video uses an AI-generated voice.

## 2.3 · Domain and range
- **Video:** `u02-l03-domain-and-range`
- **Status:** script
- **Estimated length:** 3:22 (speech 2:26 · pauses 42 s · 366 words · 4 scenes)

**Objective.** Ana finds the domain (all possible inputs) and range (all outputs) of a
function from a list, a graph, and a real context, using inequalities or interval words.

**Topics.**
- Domain = inputs, range = outputs.
- From a set of points.
- From a graph: shadows on the axes; open and closed endpoints.
- In context: what inputs make sense (whole numbers, nonnegative, limits).

#### S1 · What can go in?
*Screen:* a parking garage sign: $3 per hour, open 0 to 12 hours. `C(h) = 3h`.
> A parking garage charges three dollars an hour, and you can stay at most twelve hours. The cost is C of h equals three h.
> Can h be negative? Can h be twenty?
[REFLECT 10s] *Screen:* countdown ring.
> No. You can't park for negative time, and the garage closes after twelve hours. The inputs that make sense go from zero to twelve. Those inputs are the domain.
*Screen:* domain `0 ≤ h ≤ 12` → range `0 ≤ C ≤ 36`.
> The outputs that come out, from zero to thirty-six dollars, are the range.

#### S2 · From points
*Screen:* `{(−2, 5), (0, 1), (3, 5), (4, −1)}`; inputs circled blue, outputs green.
> For a list of points, the domain is the set of first coordinates: negative two, zero, three and four. The range is the set of second coordinates: five, one and negative one. Five appears twice, but we list it once.

#### S3 · From a graph
*Screen:* a curve from a closed dot at (−3, 2) up to (1, 6) and down to an open dot at (5, −1).
> On a graph, the domain is how far the graph reaches left to right. Imagine shining a light from above: its shadow on the x axis is the domain.
*Screen:* the shadow on the x-axis from −3 (closed) to 5 (open): `−3 ≤ x < 5`.
> This graph starts at negative three, included, and ends at five, not included because of the open dot. The domain is x from negative three up to, but not including, five.
*Screen:* a shadow on the y-axis from −1 (open) to 6 (closed).
> Now shine the light from the side. The shadow on the y axis is the range.
> Before I tell you: is negative one in the range? Look carefully at the dot.
[REFLECT 12s] *Screen:* zoom on the open dot at (5, −1); countdown ring.
*Screen:* range `−1 < y ≤ 6`.
> It isn't. The only point with y equal to negative one is the open dot, and it's not on the graph. The range is y greater than negative one, up to and including six.
*Screen:* a line with arrows on both ends.
> When a graph has arrows, it keeps going. A line like this has every real number in its domain.

#### S4 · Your turn
*Screen:* "A theater sells tickets for $8. It has 150 seats. R(t) = 8t is the revenue for t tickets sold." Give the domain and the range.
> Your turn. A theater sells tickets for eight dollars and has one hundred fifty seats. R of t equals eight t is the money from t tickets. What are the domain and the range? Pause the video and try it.
[TRY IT 20s] *Screen:* countdown ring.
*Screen:* domain: whole numbers 0, 1, 2, …, 150 · range: 0, 8, 16, …, 1200.
> The domain is the whole numbers from zero to one hundred fifty: you can't sell half a ticket. The range is zero, eight, sixteen, and so on, up to one thousand two hundred dollars.
> Remember: the domain is every input that's allowed, the range is every output that results. On a graph, look at the shadows, and watch for open dots.
> This video uses an AI-generated voice.

## 2.4 · Reading and interpreting graphs
- **Video:** `u02-l04-interpreting-graphs`
- **Status:** script
- **Estimated length:** 3:20 (speech 2:22 · pauses 42 s · 354 words · 5 scenes)

**Objective.** Ana describes a graph in words: intervals where it increases, decreases or is
constant, its intercepts, and its maximum and minimum, and connects each feature to the
situation it models.

**Topics.**
- Reading left to right.
- Increasing, decreasing, constant intervals.
- x- and y-intercepts and their meaning.
- Maximum and minimum points.
- Sketching a graph from a story.

#### S1 · A bike ride
*Screen:* a distance-from-home graph over 60 minutes: up, flat, up, down to zero.
> This graph shows Ana's distance from home during a bike ride. Time is on the horizontal axis, distance on the vertical axis.
> Before I say anything, look at it and try to tell the story of the ride.
[REFLECT 12s] *Screen:* the graph; countdown ring.
> Let's read it together, always from left to right, like a sentence.

#### S2 · Increasing, decreasing, constant
*Screen:* the first segment glows green: from 0 to 15 minutes, rising.
> From zero to fifteen minutes, the graph goes up. The function is increasing: as time goes on, she gets farther from home.
*Screen:* 15 to 25 flat, yellow.
> From fifteen to twenty-five, it's flat. The function is constant: she stopped, maybe at a park.
*Screen:* 25 to 40 rising again, 40 to 60 falling, red.
> It rises again until forty minutes, and then it decreases until sixty minutes: she's riding back home.
> Why is a flat piece of the graph not the same as her standing still at home?
[REFLECT 10s] *Screen:* the flat piece at height 3 km; countdown ring.
> Because the height of the flat piece is three kilometers. She's stopped, but three kilometers from home. Standing still at home would be flat at zero.

#### S3 · Intercepts
*Screen:* the point (0, 0) and (60, 0) marked.
> Where a graph crosses the vertical axis is the y intercept. Here it's zero: at time zero she's at home.
> Where it crosses the horizontal axis is an x intercept. At sixty minutes the distance is zero again: she's back.
*Screen:* a second graph: water in a tank, starting at 200 L and draining to 0 at 40 min.
> In this tank graph, the y intercept is two hundred liters, the starting amount. The x intercept, forty minutes, is when the tank is empty. Intercepts often mean "at the start" and "when it runs out".

#### S4 · Maximum and minimum
*Screen:* the highest point of the bike graph at (40, 5) glows.
> The highest point is the maximum. At forty minutes, she was five kilometers from home, the farthest she got. The lowest points, at zero, are the minimum.

#### S5 · Your turn
*Screen:* "A phone's battery is at 80% at 8 a.m. It drains steadily until noon, when it is at 40%. It charges from noon to 1 p.m. up to 100%, then stays there." Sketch it and name the intervals and the maximum.
> Your turn. A phone battery is at eighty percent at eight. It drains steadily until noon, down to forty percent. It charges until one o'clock, up to one hundred percent, and stays there. Sketch the graph, and name where it decreases, increases, and is constant. Pause the video and try it.
[TRY IT 20s] *Screen:* countdown ring.
*Screen:* the sketch: decreasing 8–12, increasing 12–1, constant after 1; max 100%.
> Decreasing from eight to noon, increasing from noon to one, and constant after one. The maximum is one hundred percent.
> Remember: read graphs left to right, describe where they go up, down, or stay flat, and say what every intercept and maximum means in the story.

## 2.5 · A graph is all the solutions
- **Video:** `u02-l05-graph-as-solutions`
- **Status:** script
- **Estimated length:** 3:10 (speech 2:14 · pauses 42 s · 334 words · 4 scenes)

**Objective.** Ana understands that the graph of an equation in two variables is exactly the
set of its solutions: every point on it makes the equation true and every point off it does
not; she uses this to check points and to read solutions from a graph.

**Topics.**
- A solution of an equation in two variables is a pair.
- Plotting solutions: they line up.
- On the graph ⇔ a solution.
- Reading solutions and checking points.

#### S1 · Many answers
*Screen:* `x + y = 6`.
> Find two numbers that add up to six.
[THINK 5s] *Screen:* countdown ring.
*Screen:* a list fills in: (1, 5), (2, 4), (6, 0), (−1, 7), (2.5, 3.5).
> One and five. Two and four. Six and zero. Negative one and seven. Even two point five and three point five. An equation with two variables has many solutions, and each solution is a pair.

#### S2 · The solutions line up
*Screen:* each pair plotted as a dot, one by one; they fall on one straight line.
> Let's plot every pair as a point. Look what happens. They all fall on the same line.
*Screen:* the line drawn through them.
> If we could plot every solution, including all the decimals and fractions, the points would fill in the whole line. That line is the graph of x plus y equals six.
> So what is a graph, really? Put it in your own words before I do.
[REFLECT 12s] *Screen:* the line; countdown ring.
> A graph is a picture of all the solutions. Every point on it is a solution. And every solution is a point on it.

#### S3 · Off the line
*Screen:* the point (3, 4) plotted above the line.
> Now try the point three, four. It's not on the line. Check it in the equation: three plus four is seven, not six.
> Points off the graph are exactly the pairs that don't work.
*Screen:* `y = x² − 1` graph; points (2, 3) on it, (1, 1) off it.
> It works for every equation, not just lines. On the curve y equals x squared minus one, the point two, three is on it: two squared minus one is three. The point one, one is not: one squared minus one is zero, not one.
> Why is this useful? What could a graph tell you that an equation alone makes hard to see?
[REFLECT 10s] *Screen:* the curve; countdown ring.
> A graph shows all the solutions at a glance: where they are, how they change, and which special points, like intercepts, are among them.

#### S4 · Your turn
*Screen:* `2x − y = 4`; points: (3, 2), (0, −4), (1, 1).
> Your turn. Which of these points are on the graph of two x minus y equals four? Pause the video and try it.
[TRY IT 15s] *Screen:* countdown ring.
*Screen:* (3, 2) ✓ `6 − 2 = 4` · (0, −4) ✓ `0 + 4 = 4` · (1, 1) ✗ `2 − 1 = 1`.
> Three, two works: six minus two is four. Zero, negative four works: zero minus negative four is four. One, one doesn't: two minus one is one.
> Remember: a solution of an equation in two variables is a point, and the graph is the set of all of them. On the graph means it's a solution.
> This video uses an AI-generated voice.
